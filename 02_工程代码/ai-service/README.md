# Echo Insight AI Service

## 当前职责

AI Service 只接收已经完成身份校验、权限过滤和字段裁剪的结构化项目上下文，
并输出受协议约束的风险解释或全局洞察。当前包含：

- 风险解释与全局综合的输入、输出类型；
- DeepSeek、通义千问（DashScope）与自定义 OpenAI-compatible Provider 适配器；
- 旧版 SiliconFlow 环境变量的兼容读取（不作为新安装默认项）；
- Provider 端点策略、模型适配与输出契约；
- 风险输出和全局综合结果的标准化、校验与降级；
- 不访问外部模型的 Mock 实现，供本地测试使用。

## 安全与产品边界

- 本模块不直接读取飞书，不持有用户连接凭据，也不修改项目数据。
- 模型密钥只由服务端运行环境提供，不得进入请求正文、客户端或日志。
- 健康分数、风险等级和命中规则由 Backend 的确定性规则结果提供；AI 不重新评分。
- AI 输出是解释性内容，不应被描述为已验证事实；格式不合法或 Provider 失败时应明确降级。
- Mock 输出只用于测试或明确的演示模式，不得在生产路径中伪装成真实模型成功。
