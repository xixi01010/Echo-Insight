# Echo Insight｜项目控制台

## 项目定位

Echo Insight 是一个基于飞书多来源数据的项目风险观察工具：确定性规则负责判断事实，AI 负责解释风险与整理建议，不替用户修改项目。

## 当前发布线

- 公开在线入口先让用户选择完整演示账号或飞书登录；完整只读演示无需登录、无需模型调用，包含 5 个不同健康度的合成项目、7 类信息来源与正式确定性分析链路，AI 解释使用预生成示例。
- 提供飞书登录后的真实工作区，数据可见性由应用范围、用户授权与项目成员关系共同决定。
- 在线工作区默认采用用户自带模型 Key；Key 按飞书应用账号在后端加密保存，不使用维护者 Key 兜底。
- 提供根目录安装入口与中英文自托管指南。

## 公开范围

- `00_项目控制台/`：公开项目边界与开发规范。
- `01_项目文档/`：只公开导航、风险规则与 AI 输出协议三份指定文档。
- `02_工程代码/`：公开产品源码、测试、安装与演示资产；依赖、构建输出、运行时数据和真实环境文件除外。
- 根目录：公开 README、许可证、第三方声明、商标说明、Git 规则和安装入口。

`03_资源文件/`、`04_过程记录/`、真实 `.env`、本地运行时数据与比赛过程资产不属于公开范围。

## 核心原则

- AI 只读取通过身份、成员关系与资源权限过滤后的最小必要数据。
- AI 不修改任务、负责人、截止日期、项目文档或其他项目事实。
- 健康分数、风险等级与命中原因来自确定性规则；AI 输出必须可解释、可追溯。
- 外部来源或模型失败必须显示真实的失败或部分状态。
- 任何密钥、Token、Cookie、OAuth code 或真实用户数据不得进入前端、日志、测试夹具或 Git 历史。
